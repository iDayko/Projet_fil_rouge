## Projet\_fil\_rouge



Règles de base des fichiers :


* Travailler uniquement sur ces fichiers (ou le dire explicitement)
* Travailler uniquement sur sa propre branche
* Organiser son travail de manière construite dans des fichiers de son fichier principal (Le fichier principal est le fichier à votre nom)
* Pull régulièrement sur sa branche pour éviter de perdre des données
* Push sur le main uniquement avec une partie du travail conséquente
* Mettre à jour son dossier main régulièrement avec "Fetch Origin"
* Nommé vos commit correctement avec la description de ce qu'y à été fait
* Utilisé la nomenclature correct du projet au maximum : PascalCase avec "\_" comme espace (la convention PascalCase signifie de mettre une majuscule à tout les mots pour lire plus facilement)
* Warning : Essayer d'avoir toujours au moins 1 fichier dans chaque dossier pour éviter les disparitions de dossier dans le main ou vos branches (Un fichier txt vide fonctionne)
